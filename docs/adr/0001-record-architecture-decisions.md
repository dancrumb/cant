# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-14

## Context

Cant is a language with a compiler, interpreter, language server and editor extension. Decisions about its design and tooling are easy to forget, and the reasons behind them are easy to lose.

## Decision

We record significant decisions as Architecture Decision Records in `docs/adr`, using the format in [`template.md`](template.md).

## Consequences

The reasons for past decisions are written down next to the code. Writing a record takes a little time for each significant decision.
